# 20260905_passA_pair100_repeats

9DTact pair100 반복 측정 — 2 유닛, 2 런.

같은 유닛을 **같은 프로토콜로 두 번 이상** 잰 런들이다. 각각 승자와 같은 정도로
완결돼 있다 — 사다리가 끝까지 있고, 그 단계가 결과를 남겼다. 분석이 쓰는 런은
`../20260905_passA_pair100/<유닛>` 하나이고, 여기 있는 것들은 그 유닛의 **두 번째·세 번째 측정**이다.

**버리지 말 것.** 이 캠페인에서 같은 유닛을 다시 잰 데이터는 이것뿐이다. 겔을 다시
앉히고 다시 영점을 잡았을 때 같은 숫자가 나오는가 — 재현성의 바닥 — 은 여기서만
나온다. `scripts/repeat_spread.py` 가 이것을 읽는다.

폴더 이름의 `__N` 은 그날의 몇 번째 시도였는지다. 데이터셋 폴더 밖으로 옮겨 두었으므로
어떤 glob 도 이것을 유닛으로 집지 않는다.
