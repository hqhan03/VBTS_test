## 결론 셋

1. **9DTact 가 1.8 배 멀리 읽는다** — 중앙 31.00 대 17.33 N, Mann-Whitney **p 4.8e-07**.
   범위는 겹친다(9DTact 24.6~63.2, DIGIT 11.1~23.4 N).
2. **두께에 정반대로 반응한다** — 9DTact 는 오르고(hard 30.8 → 43.6 → 61.7 N),
   DIGIT 은 내려간다(18.2 → 20.1 → 12.8 N). 세 경도 모두 방향이 같다.
3. **경도 효과는 두 원리를 비교할 수 없다** — 3 mm 에서 9DTact 2.0 배 단조, DIGIT
   1.29 배 비단조인 것은 사실이나, **9DTact 는 40 Shore 점(OO-30~70), DIGIT 은 6 점
   (OO-51~57)** 을 흔들었다. 9DTact 의 민감도(3 mm 에서 0.77 N/점)를 DIGIT 의 6 점
   범위에 적용하면 예상 변이 4.6 N, 실측 3.3 N — 같은 크기다. **DIGIT 이 둔감한 것이
   아니라 경도를 거의 바꾸지 않았다.** 이 연구가 답하지 못한 질문으로 남는다.

**기전은 포화 깊이다.** 9DTact 는 두께의 2.0~5.2 배까지 들어가 **기재에 눌린 상태**에서
포화하므로 겔의 기계적 성질이 직접 들어온다. DIGIT 은 0.56~1.32 배, 겔이 한계에 닿기
한참 전에 **광학이 먼저 포화**하므로 겔 배합을 바꿔도 그 한계가 움직이지 않는다.

## 비교에는 절대 기준을 쓴다

현행 판정은 "유닛 자신의 최대 응답의 15 %" 라는 **상대 기준**이라 **응답이 약한 유닛일수록
천장이 높게 나온다** — 복제 쌍 다섯에서 모두 그 방향이었다. 고정 문턱으로 다시 계산하면:

| 기준 | 9DTact | DIGIT | 비 | p |
|---|---:|---:|---:|---|
| 상대 (15 %) | 31.00 N | 17.33 N | 1.8× | 4.8e-07 |
| 절대 1.0 lvl/N | 30.42 N | 7.02 N | **4.3×** | 8.8e-07 |
| 절대 2.0 lvl/N | 18.10 N | 2.73 N | **6.6×** | 2.4e-03 |

상대 기준이 격차를 **압축**한다. 원리 간 비교에는 절대 기준을 쓴다.

## 공간 분해능

**DIGIT 은 가장 좁은 프로브(중심 1.10 mm = 가장자리 0.10 mm)를 18 / 18 분해한다** —
Rayleigh 기준으로도, DIGIT 360 의 MTF ≥ 0.5 기준으로도. 자국 대비가 4.0~16.9 그레이
레벨로 판정 바닥 2.5 를 크게 넘는다. **그래서 DIGIT 의 분해능 값을 말할 수 없다 —
"0.10 mm 보다 좋다" 가 이 연구가 말할 수 있는 전부다.**

9DTact 는 같은 간격에서 일부 유닛만 분해하고, 실패의 상당수는 골이 안 보여서가 아니라
**자국이 2.5 레벨에 못 미쳐 판정 자체가 불가능**했던 것이다.

## 영구 한계 (논문 Limitations)

| 한계 | 제한하는 것 |
|---|---|
| DIGIT_Marker 천장이 `ball4` 뿐 | **세 원리** 천장 비교 불가 (두 원리는 유효) |
| DIGIT_Marker 공간 분해능 미측정 | 표제 변수의 세 원리 비교 |
| DIGIT 이 가장 좁은 프로브를 18/18 분해 | DIGIT 분해능 값을 말할 수 없음 — 상한만 |
| 마커 mm/px 18 중 3 만 검증 | 픽셀 요구량 숫자 전부 |
| F/T 라벨 바닥 0.028 N (오차 바닥의 1/1.8) | 힘 추정의 **절대값** (상대 비교는 유효) |
| **경도 범위 불균형** — 9DTact 40 Shore 점 vs DIGIT **6 점** | **원리 간 경도 효과 비교 전부** |
| 변환 y 축 2.2°, 잔차 0.675 mm | 절대 깊이의 계통 성분 |
| 9DTact `medium_2mm_r1` 파괴 | 3×3 표의 한 칸이 복제 1 개 |

**프로브 간 환산은 불가능하다** — 같은 유닛을 두 프로브로 잰 18 쌍에서 힘 비가
1.50~3.26 (변동계수 21 %) 으로 흩어진다. 반면 **깊이 비는 0.99 로 1 과 구분되지 않는다**
(p 0.858): 포화 깊이는 유닛의 성질이고, 그 깊이에서의 힘은 프로브가 정한다.

```bash
python3 src/scripts/absolute_ceiling.py --thresholds 0.2,0.5,1.0,2.0

python3 src/scripts/probe_surface_offsets.py 9DTact
python3 src/scripts/probe_surface_offsets.py DIGIT

# 공간 분해능, 세 관문 판정 (유닛 하나씩)
python3 src/scripts/analyse_resolution.py 20260909_passA_pair010 DIGIT_hard_1mm_r1 pair010

# 데이터 재고 — 어느 칸이 비었나
python3 src/scripts/dataset_audit.py            # -> DATA_INVENTORY.md
```
