# 복제 감사 — 쌍둥이가 얼마나 어긋나고, 어느 쪽을 버릴 것인가

2026-09-13. 만드는 것은 `src/scripts/twin_audit.py`, 표는
`result/extra/data/{unit_metrics,twin_disagreement,trend_outliers,twin_coverage,suspect_units,replicate_choice}.csv`.

같은 (원리, 경도, 두께) 의 `r1` 과 `r2` 는 같은 물건이어야 한다. 어긋난다면 둘 중
하나가 그 겔 규격을 대표하지 못한다는 뜻이고, **복제를 하나만 쓰기로 하면 어느 쪽을
버릴지 근거가 있어야 한다.** 이 문서가 그 근거다.

> **먼저, 이미 아는 둘.** `9DTact_hard_1mm_r2` 와 `9DTact_medium_1mm_r2` 는 빛 누출이
> 확인된 유닛이다(`force_ceiling.md` §6.5c, 등록부의 `suspect_hardware`).
>
> **2026-09-13 개정: 그 둘을 빼지 않고 넣어서 잰다.** 이미 아는 결함이므로, 그것이
> 만드는 불일치의 크기가 **"알려진 결함이 지표를 얼마나 흔드는가" 의 눈금**이 된다 —
> 다른 유닛의 불일치를 그것과 견줄 수 있다. 출력에서는 `!` 로 표시한다. 아래 표 중
> 처음 판(그 둘을 뺀 채 돌린 것)에서 나온 숫자는 §2 의 셀 잔차뿐이고, 나머지는
> 둘을 넣은 값이다.

## 1. 세 가지를 따로 잰다

| 재는 것 | 무엇을 잡나 |
|---|---|
| **쌍둥이 불일치** | 같은 규격의 두 유닛이 다른 값을 낸다 |
| **경향성 이상치** | 셀 하나가 경도·두께 추세에서 벗어난다 |
| **자료량 부족** | 값이 아니라 **얼마나 쟀나**가 짝과 다르다 |

지표 14 종, 쌍 254 개, 유닛 지표 550 행.

### 1.1 불일치는 절대값으로 재면 안 된다

지표마다 정상 산포가 다르다. 쌍 상대차 `|a−b| / 평균` 의 **중앙값**:

| 지표 | 9DTact | DIGIT | DIGIT_Marker |
|---|---:|---:|---:|
| **천장 (N)** | 8.2 % | 14.4 % | 26.2 % |
| 포화 깊이 (mm) | 6.0 % | 7.5 % | 11.6 % |
| 밝기 기울기 ball8 (lvl/mm) | 7.7 % | 6.1 % | — |
| Fz 최솟값 (N) | 7.7 % | 15.0 % | 9.7 % |
| 자국 지름 기울기 ball8 (px/mm) | 8.5 % | 10.1 % | — |
| 밝기 기울기 ball4 (lvl/mm) | 9.5 % | 15.5 % | 9.7 % |
| 골 깊이 best_dip | 14.8 % | 0.0 % | — |
| Fz MAE 중앙 (N) | 7.8 % | 13.1 % | 12.8 % |
| Fy MAE 중앙 (N) | 14.7 % | 29.6 % | 21.1 % |
| Fx MAE 중앙 (N) | 26.3 % | 25.2 % | 26.9 % |
| 분해 가능한 최소 간격 (mm) | 16.8 % | 0.0 % | — |
| 형상 MAE cube4 최솟값 (mm) | 52.5 % | — | — |
| 형상 MAE cyl4 최솟값 (mm) | 41.3 % | — | — |
| 자국 지름 기울기 ball4 (px/mm) | 38.9 % | 18.6 % | 13.8 % |

**포화 깊이가 가장 좁고(6.0 %) 형상 MAE 가 가장 넓다(41 ~ 53 %).** 그래서 "20 % 차이"
는 포화 깊이에서는 큰 사건이고 형상 MAE 에서는 평범하다. 아래의 판정은 전부 **그 지표
자신의 중앙값 대비 몇 배**로 한다.

> **9DTact 의 천장 산포가 4.2 % 에서 8.2 % 로 커진 것은 빛 누출 유닛을 넣었기
> 때문이다.** 알려진 불량 둘이 그 지표의 "정상" 눈금을 두 배로 벌린다 — 눈금 자체가
> 결함에 얼마나 민감한지를 보여주는 값이라 그대로 둔다.

전체 254 쌍의 상대차 분포는 중앙 12.8 %, 90 백분위 39.1 %, 최대 90.2 % 다.

### 1.2 경향성은 설계를 먼저 빼야 한다

원리 전체의 중앙값과 견주면 **설계된 변화가 이상치로 잡힌다.** 처음에 그렇게 했더니
`9DTact_hard_3mm` 의 천장 63 N 이 robust z +6.3 으로 최상위에 올랐는데, 그것은 두께
기울기의 정당한 끝점이고 쌍둥이끼리 4.6 % 밖에 차이 나지 않는다.

그래서 셀(경도 × 두께) 중앙값으로 3×3 을 만들고 **중앙값 다듬기**(Tukey median polish)
로 `grand + 경도효과 + 두께효과` 를 뺀 뒤 잔차만 본다.

척도는 **재장착 산포**(그 지표의 쌍 반차 중앙값)를 쓴다. 이유가 둘이다 — 다듬기가
잔차를 여럿 정확히 0 으로 만들어 MAD 가 0 에 붙고 z 가 ±100 까지 튀며, 재장착 산포를
쓰면 "다시 끼웠을 때 생기는 흔들림의 몇 배" 라는 읽히는 값이 된다.

## 2. 큰 셀 잔차는 결함이 아니라 상호작용이다

잔차 상위 둘은 `9DTact` 의 천장이다.

| 셀 | 실측 | 가법 모형의 기대 | 재장착의 |
|---|---:|---:|---:|
| `hard_1mm` | 27.5 N | 43.5 N | −16.4 배 |
| `hard_3mm` | 61.7 N | 48.9 N | +13.2 배 |

**유닛 문제가 아니다.** 두께 의존이 `hard` 행에만 있기 때문이다:

| 경도 | 1 mm → 3 mm | |
|---|---|---:|
| soft | 27.3 → 30.8 N | 1.13 배 |
| medium | 31.0 → 36.3 N | 1.17 배 |
| **hard** | 27.5 → 61.7 N | **2.24 배** |

가법 모형은 상호작용을 표현할 수 없으므로 hard 행의 양 끝을 잔차로 뱉는다. 이것은
`force_ceiling.md` §6.5c 가 이미 "두께 의존은 hard 에만 있다" 로 기록한 것과 같은
사실이고, **감사의 발견이 아니라 감사의 한계**다.

> `hard_1mm` 의 27.5 N 은 **`r2` 를 뺀 채 낸 값**이라 유닛 하나에 걸려 있다. 둘을
> 넣으면 30.8 N (27.5 / 34.1) 이다. 아래 §3 의 쌍 불일치와 §4 의 복제 선택은 둘을
> 넣고 다시 돌린 값이다.

## 3. 증거가 겹치는 유닛 — 다섯 개

한 종류의 증거만으로는 어느 쪽이 이상한지 정해지지 않는다. **서로 다른 종류가 두 개
이상** 겹치는 유닛만 싣는다.

| 유닛 | 증거 |
|---|---|
| **`DIGIT_medium_3mm_r2`** | 광학 3 종이 짝과 23 ~ 63 % 어긋남(정상의 3.4 ~ 3.9 배) **+** ball4 점 **17 대 43**, 깊이폭 1.54 대 2.51 mm |
| **`DIGIT_soft_1mm_r1`** | 포화 깊이 0.96 대 1.32 mm (31 %, 4.2 배), 지름 기울기 31 % (3.1 배) **+** ball4 점 12 대 18 |
| **`9DTact_hard_1mm_r2`** ❗ | Fz 최솟값 38 % (5.0 배), 골 깊이 49 % (3.3 배) **+** ball4 점 4 대 6 — **이미 아는 빛 누출 유닛이다** |
| **`DIGIT_Marker_medium_1mm_r2`** | 밝기 기울기 4.87 대 10.34 (**72 %**, 정상의 7.4 배) **+** 점 **7 대 21**, 깊이폭 0.60 대 1.50 mm, r² 0.857 |
| **`DIGIT_medium_2mm_r2`** | 천장 22.6 대 14.1 N (**46 %**, 3.2 배) **+** ball8 점 12 대 19 |

**`9DTact_hard_1mm_r2` 가 스스로 걸려 나온 것이 이 방법의 검정이다.** 빛 누출은 감사에
입력되지 않는다 — 감사는 지표 값만 본다. 그런데도 **이미 불량으로 아는 유닛**이 서로
다른 두 종류의 증거로 목록에 올라왔다. 나머지 넷도 같은 신호를 낸다는 뜻이다.

`9DTact_medium_1mm_r2`(다른 하나의 빛 누출 유닛)는 증거가 한 종류(쌍 불일치 3 개
지표)뿐이라 이 표에 없지만, §3.1 에서 세 줄을 차지한다.

### 3.1 자료량은 멀쩡한데 값만 크게 갈리는 쌍

`!` 는 그 복제가 빛 누출 유닛이라는 뜻이다.

| 쌍 | 지표 | r1 / r2 | 정상 대비 |
|---|---|---|---:|
| `DIGIT_Marker medium_1mm` | 밝기 기울기 ball4 | 10.34 / 4.87 | **7.4 배** |
| `9DTact medium_1mm` ❗r2 | 골 깊이 `best_dip` | 0.693 / 0.274 | 5.9 배 |
| `DIGIT_Marker medium_3mm` | 지름 기울기 ball4 | 72.2 / 168.6 | 5.8 배 |
| `9DTact soft_1mm` | 밝기 기울기 ball4 | 6.17 / 10.51 | 5.5 배 |
| `9DTact soft_3mm` | 골 깊이 `best_dip` | 0.289 / 0.639 | 5.1 배 |
| `9DTact hard_1mm` ❗r2 | Fz 최솟값 | 0.024 / 0.035 N | 5.0 배 |
| `9DTact hard_3mm` | 밝기 기울기 ball8 | 8.03 / 5.53 | 4.8 배 |
| `9DTact medium_1mm` ❗r2 | 밝기 기울기 ball8 | 4.91 / 3.45 | 4.6 배 |
| `DIGIT soft_1mm` | 포화 깊이 | 0.960 / 1.315 mm | 4.2 배 |

**빛 누출 유닛 둘이 상위 여덟 줄 중 셋을 차지한다.** 그것이 "알려진 결함이 지표를
얼마나 흔드는가" 의 눈금이다 — 정상의 **4.6 ~ 5.9 배**. 그 눈금으로 보면
`DIGIT_Marker_medium_1mm`(7.4 배)과 `DIGIT_Marker_medium_3mm`(5.8 배)은 **알려진
불량보다 더 크게 어긋나 있다.**

### 3.2 절벽 문턱이 만들었던 가짜 불일치

`DIGIT_Marker_medium_1mm` 의 지름 기울기는 같은 날 **374 대 60 px/mm** 였다. 검출이
무너진 뒤의 수직 낙하를 자르는 문턱을 0.30 에서 0.70 으로 고치자 **374 대 329** 가 됐다
(`make_optical_curves.py` 의 `valid_span`). 그 쌍의 "불일치" 는 겔이 아니라 분석이
만든 것이었다.

**그러니 불일치를 발견하면 먼저 분석을 의심하는 편이 맞다.** 이 캠페인에서 그렇게
뒤집힌 것이 이번이 처음이 아니다.

## 4. 복제를 하나만 쓴다면

`replicate_choice.csv`. 지표마다 다듬기로 셀 기댓값을 구하고, 두 복제 중 **기댓값에서
먼 쪽**에 한 표씩 준다. 지표가 5 개 이상인 셀만 싣는다.

| 셀 | 지표 수 | 표 | 권고 | 표차 |
|---|---:|---|---|---:|
| `DIGIT_Marker medium_3mm` | 5 | r1 5 : r2 0 | **r1 버림** | 100 % |
| `9DTact soft_1mm` | 8 | r1 1 : r2 7 | **r2 버림** | 75 % |
| `DIGIT soft_2mm` | 5 | r1 4 : r2 1 | **r1 버림** | 60 % |
| `DIGIT hard_1mm` | 10 | r1 2 : r2 8 | **r2 버림** | 60 % |
| `9DTact soft_3mm` | 9 | r1 7 : r2 2 | r1 버림 | 56 % |
| `9DTact hard_1mm` ❗r2 | 8 | r1 6 : r2 2 | r1 버림 | 50 % |
| `9DTact medium_1mm` ❗r2 | 8 | r1 2 : r2 6 | r2 버림 | 50 % |
| `DIGIT_Marker hard_3mm` | 7 | r1 2 : r2 5 | r2 버림 | 43 % |
| `DIGIT medium_1mm` | 7 | r1 5 : r2 2 | r1 버림 | 43 % |
| `DIGIT_Marker soft_2mm` | 7 | r1 5 : r2 2 | r1 버림 | 43 % |
| `9DTact hard_2mm` | 6 | r1 4 : r2 2 | — | 33 % |
| `9DTact hard_3mm` | 9 | r1 3 : r2 6 | — | 33 % |

**표차 30 % 밑은 권고가 아니다** — 둘 중 아무거나 써도 된다는 뜻이다.

### 4.1 이 투표를 알려진 정답에 대 보면 — 둘 중 하나를 틀린다

빛 누출 유닛 둘이 **정답이 있는 시험**이다. 둘 다 `r2` 가 불량이다.

| 셀 | 투표의 답 | 정답 | |
|---|---|---|---|
| `9DTact medium_1mm` | r2 버림 (표차 50 %) | r2 | **맞음** |
| `9DTact hard_1mm` | **r1** 버림 (표차 50 %) | r2 | **틀림** |

**같은 표차 50 % 에서 하나는 맞고 하나는 거꾸로다.** 그러므로 이 투표는 **어느 유닛을
들여다볼지 고르는 데**는 쓸 수 있어도, **어느 복제를 버릴지 정하는 근거로는 약하다.**

왜 틀리는지는 §2 가 설명한다. `hard_1mm` 은 9DTact 천장의 경도×두께 **상호작용**이
가장 심한 칸이고, 가법 모형의 기댓값이 실측(27.5 / 34.1 N)에서 크게 벗어나 있다.
기댓값이 틀린 곳에서는 "기댓값에서 먼 쪽" 이 뒤집힌다.

### 4.2 이 투표의 편향

**추세에 가까운 쪽을 남기는 방식이므로 그 자체로 추세를 강화한다.** 복제 둘의 평균이
참값이라면 이 선택은 산포를 줄이는 대신 **효과 크기를 부풀린다.**

그래서 이렇게 쓰는 것이 안전하다:

1. **결론에 쓸 지표가 정해지면 그 지표 하나로 다시 고른다.** 열네 지표의 투표는
   어느 유닛을 들여다볼지 정하는 데 쓰고, 최종 선택의 근거로는 쓰지 않는다.
2. **§3 의 다섯 유닛처럼 독립적인 증거(자료량)가 있는 경우**가 가장 안전한 제외다 —
   값이 아니라 측정 자체가 부족했다는 뜻이므로 추세와 무관하고, §4.1 이 보여주듯
   추세 기반 투표보다 믿을 만하다.
3. **복제 둘을 다 쓰고 유닛을 임의효과로 두는 편이 낫다면 그렇게 한다.** 하나를
   버리는 것은 자유도를 잃는 대신 해석을 단순하게 만드는 거래다.

python3 src/scripts/twin_audit.py
